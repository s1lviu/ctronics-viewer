# Runtime notices

Original notices for compression libraries that may be included with Python.

- BZIP2.txt: https://sourceware.org/git/?p=bzip2.git;a=blob_plain;f=LICENSE;hb=bzip2-1.0.8
- XZ.txt: https://raw.githubusercontent.com/tukaani-project/xz/v5.2.5/COPYING

The bundler also copies Windows Python distribution notices or Ubuntu runtime package notices directly from each native build environment. Python acknowledgments cover additional incorporated components.
